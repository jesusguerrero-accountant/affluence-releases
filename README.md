# Affluence · descargas

Instaladores de Affluence para Windows.

Descarga la versión más reciente en la sección **Releases** de este repositorio.

Cada versión incluye:

- `Affluence-Setup-X.Y.Z.exe`: el instalador.
- `Affluence-Setup-X.Y.Z.exe.sha256`: la huella para comprobar la descarga.
- `actualizacion.json` y `actualizacion.json.sig`: los usa la aplicación para actualizarse sola de forma segura.
